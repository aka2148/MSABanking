<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → Spring Boot API | Untrusted browser requests cross into authenticated FD endpoints. |
| Browser storage → Angular services | Persisted token/role state is client-controlled and may be absent or expired. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-06-01 | Spoofing | auth interceptor/session | mitigate | Send only the persisted bearer token, clear it on 401, and protect navigation with the guard; backend remains authority. |
| T-06-02 | Information disclosure | auth service/logging | mitigate | Never log token, password, request body, or credentials; keep URLs free of secrets. |
| T-06-03 | Tampering/replay | FD writes | mitigate | Generate and reuse `Idempotency-Key` per active submission and render backend 409 responses without inventing success. |
</threat_model>
