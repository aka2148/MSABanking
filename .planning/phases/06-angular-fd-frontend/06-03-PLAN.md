<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Route account id → backend read/write | URL path id is untrusted and must rely on backend ownership responses. |
| Backend financial response → user display | Returned amounts/statuses are authoritative and must not be reconstructed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-06-07 | Elevation of privilege | account actions | mitigate | Derive UI actions from status only for usability, never infer authorization; render backend 404/403/409 responses and send no holder id. |
| T-06-08 | Tampering | account id route | mitigate | Use the backend account endpoint and ownership policy as authority; do not expose cross-customer list/search controls. |
| T-06-09 | Denial/replay | lifecycle writes | mitigate | Disable busy controls, confirm final actions, reuse idempotency key on retry, and refresh server state after every successful write. |
</threat_model>
